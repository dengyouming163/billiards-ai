## 五、风险与注意事项

1. **接口路径格式**: 确保使用正确的 ThinkPHP 格式 `/模块名.控制器/方法名`
2. **store_id 公共参数**: 所有业务接口需携带 store_id 参数
3. **数据类型匹配**: 注意 ID 类型（string vs number）
4. **错误处理**: API 调用失败时显示友好提示
