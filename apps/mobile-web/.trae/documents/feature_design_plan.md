# 球房管理系统功能设计方案

## 一、项目背景分析

当前问题：用户反馈页面只有"关于"和"退出登录"，说明：
1. 设置页面内容过于单薄
2. 角色权限配置可能未正确生效
3. 功能模块需要完整规划

## 二、目标用户与角色定位

### 2.1 用户角色定义

| 角色 | 职责描述 | 系统权限 |
|-----|---------|---------|
| **老板** | 全局管理、数据监控、决策分析 | 全部功能 |
| **管理员** | 日常运营、员工管理、审批处理 | 除财务外全部功能 |
| **店长** | 门店管理、员工排班、订单分配 | 门店级管理功能 |
| **助教** | 接单服务、业绩追踪、考勤打卡 | 服务执行功能 |
| **普通员工** | 基础打卡、申请提交、排班查看 | 基础功能 |

## 三、功能模块设计

### 3.1 首页/数据看板（老板/管理员/店长）

**核心功能：**
- 今日营收统计
- 订单数量趋势
- 员工打卡状态
- 待处理审批数
- 预警通知提醒

**页面路径：** `/pages/index/index`

### 3.2 订单管理模块

**核心功能：**
- 待接单列表
- 进行中订单
- 订单历史记录
- 订单完成确认

**页面路径：** 
- `/pages/orders/index` - 接单中心
- `/pages/orders/active` - 进行中订单

### 3.3 员工管理模块（老板/管理员/店长）

**核心功能：**
- 员工列表展示
- 员工详情查看
- 员工信息编辑
- 密码重置

**页面路径：**
- `/pages/employee/list` - 员工列表
- `/pages/employee/detail` - 员工详情

### 3.4 审批中心模块（老板/管理员/店长）

**核心功能：**
- 待审批列表
- 审批历史记录
- 通过/拒绝操作
- 审批详情查看

**页面路径：**
- `/pages/approval/index` - 审批中心
- `/pages/approval/detail` - 审批详情

### 3.5 考勤打卡模块

**核心功能：**
- 今日打卡签到
- 打卡记录查询
- 外勤申请
- 补签申请

**页面路径：**
- `/pages/checkin/index` - 打卡签到
- `/pages/checkin/record` - 打卡记录
- `/pages/checkin/outwork` - 外勤申请

### 3.6 业绩统计模块（助教/店长/管理员/老板）

**核心功能：**
- 个人业绩统计
- 业绩趋势图表
- 提成计算展示

**页面路径：** `/pages/performance/index`

### 3.7 排班管理模块

**核心功能：**
- 个人排班查看
- 排班调整申请
- 班表展示

**页面路径：** `/pages/schedule/index`

### 3.8 申请中心模块（员工/助教）

**核心功能：**
- 补签申请
- 请假申请
- 申请记录查询

**页面路径：**
- `/pages/apply/checkin` - 补签申请
- `/pages/apply/leave` - 请假申请
- `/pages/apply/record` - 申请记录

### 3.9 预警通知模块

**核心功能：**
- 通知列表展示
- 通知详情查看
- 标记已读/全部已读

**页面路径：**
- `/pages/notification/index` - 通知列表
- `/pages/notification/detail` - 通知详情

### 3.10 个人中心/设置模块

**核心功能：**
- 个人资料查看/编辑
- 修改密码
- 系统设置
- 关于我们
- 退出登录

**页面路径：**
- `/pages/profile/index` - 个人资料
- `/pages/settings/index` - 设置页面

## 五、设置页面完善

当前设置页面只有"关于"和"退出登录"，需要增加：

| 功能项 | 说明 | 优先级 |
|-------|------|-------|
| 个人资料 | 查看/编辑个人信息 | 高 |
| 修改密码 | 修改登录密码 | 高 |
| 通知设置 | 通知开关配置 | 中 |
| 账号安全 | 绑定手机/邮箱 | 中 |
| 帮助中心 | 使用帮助文档 | 低 |
| 关于我们 | 版本信息 | 低 |
| 退出登录 | 退出当前账号 | 高 |

## 六、实现计划

### 6.1 第一阶段：完善设置页面

1. 更新 `pages/settings/index.vue`，添加完整的设置菜单
2. 确保个人资料页面可访问

### 6.2 第二阶段：验证权限配置

1. 检查 `authStore` 的角色获取逻辑
2. 验证 `MENU_CONFIG` 配置正确性
3. 确保 TabBar 组件正确渲染

### 6.3 第三阶段：功能完整性检查

1. 验证各角色页面跳转正确性
2. 确保 API 调用正常
3. 修复潜在的功能断点
