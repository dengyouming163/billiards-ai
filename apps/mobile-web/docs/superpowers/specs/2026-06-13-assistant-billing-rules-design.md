# 助教计费规则 — 可配置化设计

> 日期: 2026-06-13 | 状态: 设计中

## 背景

当前助教统一按 X元/小时 计费，无法灵活处理不满一小时的场景。球房实际运营中通常采用两种模式之一，应由管理者自行选择。

## 配置项

在 wwwstore 后台助教配置页新增：

```
┌─────────────────────────────────────────────┐
│  计费方式                                      │
│                                               │
│  ○ 按分钟计费 — 精确到分钟，公平透明              │
│    示例：80元/小时，服务70分钟                    │
│    70 ÷ 60 × 80 = 93.33 元                     │
│                                               │
│  ● 以半小时为计费单位 — 不满半小时按半小时算        │
│    示例：80元/小时，服务70分钟                    │
│    70分钟 → 1.5小时 → 1.5 × 80 = 120 元         │
│                                               │
│  推荐：以半小时为计费单位（行业通用做法）            │
└─────────────────────────────────────────────┘
```

## 计费算法

### 方式一：按分钟计费 `minute`

```
费用 = round(服务分钟数 / 60 × 时薪, 2)
```

### 方式二：半小时计费 `half_hour`

```
计费单位数 = ceil(服务分钟数 / 30)
计费小时数 = 计费单位数 × 0.5
费用 = 计费小时数 × 时薪
```

| 服务时长 | 计费时长 | 80元/h |
|---------|---------|--------|
| 1-30分 | 0.5h | 40元 |
| 31-60分 | 1h | 80元 |
| 61-90分 | 1.5h | 120元 |
| 91-120分 | 2h | 160元 |

## 数据结构

### 数据库

```sql
ALTER TABLE assistant ADD COLUMN billing_rule VARCHAR(16) DEFAULT 'half_hour';
-- 或 assistant_level 表

billing_rule 取值: 'minute' | 'half_hour'
默认值: 'half_hour'（向后兼容，已有助教默认半小时计费）
```

### API 参数

```
POST/GET assistant 相关接口新增字段:
{ "billing_rule": "half_hour" | "minute" }
```

## 影响范围

| 层 | 文件/模块 | 改动 |
|----|----------|------|
| 数据库 | `assistant` 或 `assistant_level` | 加 `billing_rule` 列，默认 `half_hour` |
| wwwapi | 助教 CRUD Controller | 增删改查支持 `billing_rule` |
| wwwapi | 结算 Controller | `endAssistant` 根据 `billing_rule` 计算 `final_price` |
| wwwstore | 助教配置页面 | 加计费方式 Radio + 示例说明 |
| wwwstoreapp | 无 | 只接收后端算好的金额 |

## 验收标准

1. wwwstore 助教编辑页可选择两种计费方式，并展示示例说明
2. 按分钟模式：服务 70 分钟，80元/h → 显示 93.33 元
3. 半小时模式：服务 70 分钟，80元/h → 显示 120 元
4. 已结算订单的助教费用正确回填
