# 助教接单页 UI 重设计规格

**日期:** 2026-06-22 | **风格:** 极简渐变 A | **目标:** 重写 AssistantHome.vue 样式

---

## 视觉规范

| 元素 | 规格 |
|------|------|
| 主色调 | `#059669` (翠绿) → `#10b981` (浅绿) |
| 背景 | `#f2f3f5` |
| 卡片 | 白色 `#fff`，圆角 16-20rpx，阴影 `0 2px 12px rgba(0,0,0,.04)` |
| 状态卡片 | 绿渐变（在线）/ 灰渐变（离线）/ 蓝渐变（服务中） |
| Tab | 选中绿底白字，未选中灰底 `#f3f4f6` |
| 金额 | 绿色 `#059669`，bold 16px |
| 按钮 | 圆角 10-14rpx |
| 字体 | PingFang SC, -apple-system |

## 组件结构

```
AssistantHome.vue
├── 状态卡片 (.status-card)
│   - 在线: bg-gradient(135deg, #059669, #10b981), 白字
│   - 离线: bg-gradient(135deg, #64748b, #94a3b8), 白字
│   - 服务中: bg-gradient(135deg, #2563eb, #3b82f6), 白字
│   - 布局: 头像 + 姓名/收入 + 状态徽标 [上线/下线按钮]
├── 接单标题栏
│   - "接单列表" + "📋 我的订单 →"
├── 筛选 Tab (横向滚动)
│   - 选中: 绿底白字
│   - 未选中: 灰底 #f3f4f6
├── 订单卡片 (.order-card)
│   - 桌号 + 订单号 + 状态徽标
│   - 客户 / 金额(绿色大字) / 计时(蓝色)
│   - 操作区:
│     pending → "等待收银确认"（灰字）
│     accepted → [开始服务] 绿按钮
│     in_progress → [结束服务] 橙按钮
│     completed → "✅ 已完成"（绿字）
└── 15s 轮询 + 1s 计时器
```

## 状态徽标颜色

| 状态 | 背景 | 文字 |
|------|------|------|
| pending (待确认) | `#fef3c7` | `#d97706` |
| accepted (已确认) | `#dbeafe` | `#2563eb` |
| in_progress (服务中) | `#dbeafe` | `#2563eb` |
| completed (已完成) | `#d1fae5` | `#059669` |
