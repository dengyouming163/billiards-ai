# AssistantHome 助教角色首页重构设计

## 一、问题分析

### 当前页面问题
1. **信息密度过低**：hero-card 中描述文字"快速查看上线状态、今日收入和当前订单，操作更集中，页面更松弛"是无效信息，占据大量空间
2. **布局松散**：卡片间距过大（22rpx），内边距偏大，导致一屏显示内容太少
3. **视觉层次混乱**：用户状态和接单列表之间缺乏有效分隔
4. **操作按钮偏小**：上线/下线按钮和订单操作按钮尺寸偏小，不利于快速操作

### 核心需求
- 采用大组件、大圆角布局
- 提高信息密度，减少无效信息
- 保持项目统一风格（主色调 #059669，渐变背景，大圆角）
- 不改动功能逻辑

#### 设计要点

| 模块 | 设计规格 |
|------|----------|
| 综合Hero Card | 大圆角 48rpx，渐变背景（#059669 → #10b981），内边距 36rpx |
| 用户信息区域 | 头像 64rpx，姓名 32rpx 粗体，今日收入 48rpx 粗体白色 |
| 统计卡片 | 双栏布局，方形卡片（圆角 20rpx），数值 36rpx，标签 24rpx |
| 状态切换区 | 状态文字 28rpx，开关按钮加大（width: 120rpx, height: 64rpx） |
| 订单卡片 | 大圆角 36rpx，内边距 32rpx，网格布局展示客户/金额/计时/状态 |
| 操作按钮 | 高度 88rpx，圆角 44rpx，渐变背景，文字 30rpx 粗体 |

#### 状态标签颜色规范

| 状态 | 背景色 | 文字色 |
|------|--------|--------|
| 待确认 | rgba(255, 149, 0, 0.1) | #e67c00 |
| 已确认 | rgba(59, 130, 246, 0.1) | #3b82f6 |
| 服务中 | rgba(59, 130, 246, 0.1) | #3b82f6 |
| 已完成 | rgba(52, 199, 89, 0.1) | #22c55e |

#### 交互优化
- 上线/下线按钮加大尺寸，方便快速切换
- 订单卡片内状态标签颜色区分
- 服务计时采用等宽字体，实时更新
- 取消Tab筛选，改为卡片内状态标签展示

- `profile.name` - 助教姓名

## 四、设计规范

### 统一风格
- 主色调：`#059669`（emerald-600）
- 渐变背景：`linear-gradient(135deg, #059669, #10b981)`
- 大圆角：`36rpx ~ 48rpx`
- 阴影：`0 12rpx 36rpx rgba(15, 23, 42, 0.06)`
- 字体：Inter，无衬线字体
- 按钮样式：渐变背景，大圆角，阴影效果

### 间距规范
- 页面内边距：`30rpx 24rpx`
- 卡片间距：`20rpx`
- 卡片内边距：`32rpx`

### 字体规范
- 大标题：48rpx，font-weight: 800
- 小标题：32rpx，font-weight: 700
- 正文：28rpx，font-weight: 500
- 辅助文字：24rpx，font-weight: 400
