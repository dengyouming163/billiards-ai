# 离线计费系统 — 手动测试指南

> 日期: 2026-06-08 | 测试环境: H5 (浏览器 DevTools)

---

## 0. 前置准备

### 启动后端

```bash
# 终端 1: 启动 PHP 后端
cd wwwapi && php think run --host 0.0.0.0 --port 10002

# 终端 2: 启动 wwwtable
cd wwwtable && npm run dev:h5
```

### 模拟断网

在浏览器 DevTools → Network 标签 → 勾选 **Offline**（或 Throttling → Offline）
