# wwwstore 微信UI风格全量重构设计文档

## 1. 概述

### 1.1 重构目标
将 wwwstore 管理后台从当前的 Emerald 绿色系风格，全量重构为微信管理后台风格，使用微信绿 `#07C160` 作为主色，配合大圆角设计，打造颠覆性的视觉体验。

### 1.2 约束条件
- 不改动任何功能逻辑，只修改样式和布局
- 所有"台屏智联"文字替换为"客稻云"
- 保持侧边栏+内容区的 Admin Dashboard 布局结构

### 1.3 设计原则
- 微信管理后台风格：简洁、清爽、专业
- 大圆角设计：柔和、现代感
- 色彩统一：微信绿为主色，白色卡片，浅灰背景

## 2. 色彩系统

### 2.1 主色调
| 色彩类型 | HEX值 | 用途 |
|----------|-------|------|
| 主色 | `#07C160` | 按钮、链接、高亮元素、图标 |
| 主色深 | `#06AD56` | 按钮hover状态 |
| 主色浅 | `rgba(7, 193, 96, 0.1)` | 背景高亮 |

### 2.2 背景与卡片
| 色彩类型 | HEX值 | 用途 |
|----------|-------|------|
| 页面背景 | `#f7f7f7` | 全局页面背景 |
| 卡片背景 | `#ffffff` | 内容卡片、侧边栏 |

### 2.3 文字层级
| 色彩类型 | HEX值 | 用途 |
|----------|-------|------|
| 主标题 | `#000000` | 大标题、重要文字 |
| 正文字 | `#333333` | 正文内容 |
| 辅助文字 | `#999999` | 提示、说明文字 |

### 2.4 边框与分割
| 色彩类型 | HEX值 | 用途 |
|----------|-------|------|
| 边框色 | `#e5e5e5` | 卡片边框、分割线 |
| 分割线 | `#f5f5f5` | 内部分割线 |

### 2.5 状态颜色
| 状态 | HEX值 | 用途 |
|------|-------|------|
| 成功/使用中 | `#07C160` | 台桌使用中、操作成功 |
| 警告/预约 | `#FF976A` | 台桌预约、警告提示 |
| 空闲 | `#999999` | 台桌空闲 |
| 维护 | `#CCCCCC` | 台桌维护中 |
| 危险 | `#FF5252` | 删除、退出等危险操作 |

### 4.2 顶部导航栏
- 高度：`48px`
- 背景：`#ffffff`
- 边框：底部 `1px solid #e5e5e5`
- 左侧：品牌Logo（微信绿渐变）+ "客稻云"文字
- 中间：门店切换下拉
- 右侧：通知图标、帮助图标、用户头像下拉

### 4.3 侧边栏
- 宽度：`224px`（展开）/ `64px`（折叠）
- 背景：`#ffffff`
- 圆角：右上角和右下角 `24px`
- 边框：`1px solid #e5e5e5`
- 门店选择器：顶部独立区域
- 菜单项：图标+文字，绿色激活态

### 4.4 内容区域
- 背景：`#f7f7f7`
- 卡片间距：`24px`
- 卡片样式：白色背景、浅灰边框、大圆角

## 5. 核心组件样式

### 5.1 Hero区域
- 背景：绿色渐变 `linear-gradient(135deg, #07C160, #06AD56)`
- 圆角：`32px`
- 文字：白色
- 装饰：模糊圆形光晕

### 5.2 数据卡片
- 背景：`#ffffff`
- 圆角：`24px`
- 边框：`1px solid #e5e5e5`
- 图标区域：绿色背景圆角 `16px`
- 悬浮效果：阴影加深，轻微上移

### 5.3 快捷操作按钮
- 背景：绿色渐变 `linear-gradient(135deg, #07C160, #06AD56)`
- 圆角：`20px`
- 图标：白色，`24px`
- 文字：白色，`14px`
- 悬浮效果：阴影加深，轻微上移

### 5.4 台桌状态卡片
- 空闲：白色背景，灰色边框
- 使用中：浅绿色背景，绿色边框
- 预约：浅橙色背景，橙色边框
- 维护：浅灰背景，灰色边框
- 圆角：`20px`

### 5.5 按钮样式
- 主按钮：绿色渐变，白色文字，胶囊形
- 次按钮：白色背景，灰色边框，胶囊形
- 危险按钮：红色背景，白色文字，胶囊形

## 8. 交互效果

### 8.1 悬停效果
- 卡片：阴影加深，轻微上移 `transform: translateY(-2px)`
- 按钮：阴影加深，轻微上移
- 菜单项：背景高亮

### 8.2 过渡动画
- 侧边栏折叠：`transition-all duration-300`
- 卡片加载：`animate-fade-in`
- 弹窗显示：`animate-scale-in`
