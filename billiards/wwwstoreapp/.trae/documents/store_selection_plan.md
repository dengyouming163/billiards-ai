# 门店选择功能完善方案

## 一、现状分析

### 1.1 问题识别

| 问题 | 当前状态 | 影响 |
|------|----------|------|
| 门店列表未自动加载 | 仅在点击门店选择器时加载 | 用户登录后无法看到门店列表 |
| 无默认选中逻辑 | 依赖缓存或用户手动选择 | 首次登录可能没有选中门店 |
| 全局缓存不完整 | 仅缓存 storeId 和 storeName | 缺少完整门店信息缓存 |
| 接口调用缺少store_id | 需要确保每个接口都传递 | 数据查询可能出错 |

### 1.2 当前流程

```
用户登录 → 首页加载 → 手动点击门店选择器 → 加载门店列表 → 选择门店 → 缓存storeId/storeName
```

### 1.3 期望流程

```
用户登录 → 自动加载门店列表 → 默认选中第一个门店 → 缓存完整门店信息 → 所有接口自动带上store_id
```

---

## 二、优化方案

### 2.1 更新 StoreStore

**目标**：添加门店列表管理和自动选择逻辑

**修改文件**：`src/stores/store.ts`

**新增功能**：
- 添加 `storeList` 数组存储门店列表
- 添加 `loadStoreList()` 方法加载门店列表
- 添加 `selectFirstStore()` 方法默认选择第一个门店
- 完善缓存机制

### 2.2 更新登录流程

**目标**：登录成功后自动加载并选择门店

**修改文件**：`src/stores/auth.ts`

**修改内容**：
- 在 `login()` 成功后调用门店列表加载
- 在 `initFromStorage()` 时检查是否有缓存的门店

### 2.3 更新首页加载逻辑

**目标**：确保首页加载前已选择门店

**修改文件**：`pages/index/index.vue`

**修改内容**：
- 在 `checkLogin()` 中等待门店加载完成
- 如果没有门店列表，显示门店选择提示

### 2.4 确保请求自动携带 store_id

**目标**：所有API请求自动带上当前门店ID

**修改文件**：`src/api/request.ts`

**修改内容**：
- 在请求拦截器中自动添加 `store_id` 参数
